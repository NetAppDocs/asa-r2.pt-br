= Determine os limites de armazenamento do seu sistema ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Conhecer os limites de storage do seu sistema ASA r2 ajuda você a configurá-lo para obter o melhor desempenho e suporte. Você pode consultar os limites do seu sistema e da versão do ONTAP no NetApp Hardware Universe.

Os limites podem variar com base no seu sistema ASA r2 e na sua versão do ONTAP. Consulte link:https://hwu.netapp.com/["NetApp Hardware Universe"^] para obter uma lista completa dos limites mais atuais do seu sistema específico.


NOTE: Os limites de máquinas virtuais (VMs) não estão listados no Hardware Universe. O número máximo recomendado de VMs por par de HA é 800 e por cluster é 1.200, com base nos limites de volume do sistema ASA r2. Esse limite não se aplica a VMs residentes em datastores VMFS. Não há número máximo de VMs para datastores VMFS.

.Sobre esta tarefa
Os sistemas ASA r2 estão listados no NetApp Hardware Universe em *Produtos* como plataformas "ASA".

.Passos
. Acesse link:https://hwu.netapp.com["NetApp Hardware Universe"^].
. Selecione *Produtos*.
. Em *Plataformas*, selecione *ASA* como seu tipo de sistema.
. Selecione o seu sistema específico e, em seguida, selecione a sua versão do ONTAP.
. Selecione *Mostrar resultados*.


.Resultados
Os limites suportados para o seu sistema ASA r2 específico e versão do ONTAP são exibidos.
