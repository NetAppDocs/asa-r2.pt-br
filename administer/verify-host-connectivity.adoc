= Verifique a conectividade de host no sistema de storage ASA R2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se houver um problema com as operações de dados do host, use o Gerenciador de sistema do ONTAP para verificar se a conexão do host ao sistema de storage do ASA R2 está ativa.

.Passos
. No System Manager, selecione *Host*.
+
O System Manager exibe o status de conectividade de host ao lado do nome do grupo de hosts:

+
** *OK*: indica que todos os iniciadores estão conectados a ambos os nós.
** *Parcialmente Conectado*: Indica que alguns dos iniciadores não estão conectados a ambos os nós.
** *Nenhum conetado*: Indica que nenhum iniciador está conetado.




.O que se segue?
Faça as atualizações necessárias no seu host para corrigir problemas de conectividade. O ONTAP verificará novamente o status da conexão a cada 15 minutos.
