= Enviar e exibir casos de suporte para sistemas de storage ASA R2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se você tiver um problema que exija assistência, use o ONTAP System Manager para enviar uma solicitação ao suporte técnico ou para visualizar casos que foram fechados ou estão em andamento.

Você precisa estar link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Registrado no Active IQ"^] para visualizar os casos de suporte do seu sistema ASA r2.

.Passos
. Para enviar uma solicitação de suporte, no System Manager, selecione *Cluster > Suporte*; em seguida, selecione *Ir para NetApp Support*.
. Para visualizar um caso previamente submetido, no System Manager, selecione *Cluster > Suporte*; em seguida, selecione *Visualizar meus casos*.
