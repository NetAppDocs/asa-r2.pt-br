= Desative a proteção autônoma contra ransomware padrão em sistemas de storage ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ao inicializar um novo cluster ASA ONTAP 9.18.1 r2 ou atualizar um cluster para ONTAP 9.18.1, o ARP/AI é ativado por padrão em todas as novas unidades de storage após um período de carência de 12 horas. Se você não desativar o ARP/AI durante esse período, o ONTAP o ativa em todo o cluster para novas unidades de storage quando o período de carência termina.

As unidades de armazenamento criadas no ONTAP 9.17.1 devem ser link:enable-anti-ransomware-protection.html["ativado manualmente"] para ARP/AI.

.Passos
Você pode desativar a capacitação padrão durante ou após o período de carência inicial de 12 horas.

[role="tabbed-block"]
====
.System Manager
--
. Selecione *Cluster > Settings*.
. Desativar ARP:
+
** Para desativar durante o período de carência de 12 horas:
+
... Em *Anti-ransomware*, selecione *Não ativar* e, em seguida, selecione *Desativar*.


** Para desativar após o período de carência de 12 horas:
+
... Em *Anti-ransomware*, selecione image:icon_pencil.gif["Editar"] e desmarque *Ativar para novas unidades de armazenamento*.
... Selecione *Save*






--
.CLI
--
. Verifique o status de capacitação padrão:
+
[source, cli]
----
security anti-ransomware auto-enable show
----
. Desative a capacitação padrão para unidades de storage existentes e novas:
+
[source, cli]
----
security anti-ransomware auto-enable modify -default-existing-volume-state false -default-new-volume-state false
----
